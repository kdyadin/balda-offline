# Цель

Выпустить Android-игру «Балда» для двух игроков на одном устройстве (hot-seat): полностью офлайн-геймплей с проверкой слов по встроенному словарю и толкованиями слов по словарю, докачиваемому один раз при первом запуске.

# Описание задачи

## Контекст

Классическая игра в слова на бумаге. На поле N×N в центральную строку вписано стартовое слово. Игроки по очереди ставят одну букву в пустую клетку и составляют новое слово, проходящее через эту букву. Очки = количество букв в составленном слове. Побеждает набравший больше очков.

Приложение делается для игры вдвоём на одном телефоне, без сети, без аккаунтов, без рекламы и аналитики.

## Критическое ограничение

**Игра обязана быть полностью играбельной офлайн.** Из этого следуют два жёстких требования:

1. Список допустимых слов (проверка валидности хода) и список стартовых слов **упаковываются в APK**. Без них игра не запускается — сеть для геймплея не нужна никогда.
2. Разрешение `INTERNET` используется **только** для одноразовой загрузки базы толкований при первом запуске. Если пользователь отказался или сети нет — игра работает в полном объёме, просто в карточке слова вместо толкования показывается «Толкование не загружено» и кнопка «Загрузить словарь толкований» (доступна в настройках в любой момент).

## Технологический стек

- Kotlin, Jetpack Compose, Material 3
- minSdk 26, targetSdk актуальный
- Single Activity, MVVM: ViewModel + `StateFlow`, доменный слой без зависимостей от Android
- Корутины, DataStore (настройки и имена игроков), SQLite/Room (толкования)
- Все игровые правила — в чистом доменном модуле, покрытом unit-тестами
- Никаких сторонних SDK аналитики, рекламы, краш-репортинга

## Настройки перед стартом партии

Экран новой игры содержит:

1. **Размер поля / длина слова**: 5×5, 6×6, 7×7 (по умолчанию 5×5). Длина стартового слова = N, слово вписывается в центральную строку. Пустых клеток всегда N²−N — число чётное при любом N, то есть ходов у игроков поровну.
2. **Стартовое слово**: выбирается случайно из встроенного списка существительных нужной длины. Кнопка «Другое слово» для переброса. В рамках одной сессии слова не повторяются.
3. **Имена игроков**: по умолчанию «Игрок 1» и «Игрок 2», оба редактируются, последние введённые имена сохраняются и подставляются в следующей партии.
4. **Кто ходит первым**: либо ручной выбор игрока, либо «Бросить жребий» — случайный выбор с короткой анимацией и явным показом результата.
5. **Таймер на ход**: выкл / 30 / 60 / 120 секунд (по умолчанию выкл).
6. **Подсказки**: лимит на игрока (0 / 1 / 3 / без ограничений, по умолчанию 1) и штраф за подсказку.

## Правила игры (ядро)

**Ход игрока:**
1. Игрок выбирает пустую клетку и ставит в неё одну букву (клавиатура русского алфавита внутри приложения, включая Ё).
2. Затем выделяет слово, последовательно тапая по клеткам пути (либо ведя пальцем). Выделенные клетки подсвечиваются, составляемое слово показывается над полем.
3. Кнопка «Подтвердить» активна только когда слово прошло все проверки.

**Валидация слова — все условия обязательны:**
- За ход ставится ровно одна новая буква.
- Путь идёт по соседним клеткам по горизонтали и вертикали, **диагонали запрещены**.
- Каждая клетка используется в слове не более одного раза.
- Путь обязан проходить через только что поставленную букву.
- Слово есть во встроенном словаре (нарицательное существительное в именительном падеже единственного числа; множественное — только для слов без формы единственного числа).
- Слово не совпадает со стартовым словом.
- Слово не было составлено ранее ни одним из игроков в этой партии.
- Слово ещё не читалось на поле до этого хода: проверить обходом в глубину по уже заполненным клеткам (без новой буквы), существует ли для него допустимый путь. Если существует — ход отклоняется.

При отклонении — понятное сообщение о конкретной причине («Такого слова нет в словаре», «Слово уже составлено игроком Инна», «Нельзя ходить по диагонали»), поставленная буква и выделение сбрасываются, ход остаётся у того же игрока.

**Пас:** если игрок не может составить слово, он пропускает ход. Если оба игрока пасуют три раза подряд — партия завершается.

**Истёкший таймер:** ход автоматически засчитывается как пас, поставленная буква снимается.

**Подсказка:** приложение находит любое валидное слово и показывает его (само слово, без пути, чтобы игрок сам его нашёл, — либо с путём, если исчерпан лимит времени). Стоимость: −5 очков из счёта игрока, лимит по настройкам. Использование подсказки отмечается в журнале партии.

**Сдаться:** игрок может завершить партию досрочно. Его счёт обнуляется до нуля, победа присуждается сопернику. Требуется подтверждение в диалоге.

**Передача телефона:** после подтверждённого хода (и после паса) показывается промежуточный экран-заслонка с текстом «Передай телефон: ходит <имя>» и кнопкой «Готов». Поле на этом экране не видно, чтобы следующий игрок не подсматривал варианты заранее. Экран можно отключить в настройках.

**Окончание партии:** все клетки заполнены, либо шесть пасов подряд (по три у каждого), либо один игрок сдался.

**Подсчёт очков:** 1 буква = 1 очко за каждое составленное слово. Минус штрафы за подсказки. Итоговый экран: победитель, счёт обоих, полный список слов каждого игрока с длиной, тап по слову открывает его толкование. При равенстве очков — ничья. Кнопки «Играть ещё раз с теми же настройками» и «В меню».

## Словарная подсистема

**Словарь проверки слов (в APK, обязателен):**
- Источник — открытые данные: OpenCorpora (CC-BY-SA) или Hunspell `ru_RU` (MPL-2.0 / LGPL). Отфильтровать: только нарицательные существительные в начальной форме, длина от 2 до N², без имён собственных, аббревиатур и дефисов.
- Ё нормализуется в Е на этапе сборки словаря и при проверке ввода, чтобы «ёж» и «еж» считались одним словом.
- Формат хранения — DAWG/префиксное дерево в бинарном виде в `assets` либо отсортированный массив + бинарный поиск. Ограничения: загрузка при старте < 1 с, проверка слова < 10 мс, поиск подсказки < 2 с, размер не более ~10 МБ.
- Подготовка словаря выносится в отдельный скрипт (`tools/build-dictionary/`) с README: откуда взяты данные, как отфильтрованы, как пересобрать. Лицензионные тексты — в экране «О программе».

**Словарь толкований (докачка при первом запуске):**
- Источник — дамп русского Викисловаря (CC-BY-SA) или аналогичная открытая база, приведённая к виду `лемма → краткое толкование` (1–2 предложения на значение, максимум 3 значения).
- Собранная SQLite-база выкладывается отдельным файлом (например, GitHub Releases) и скачивается один раз, с проверкой SHA-256, показом прогресса и корректной обработкой обрыва связи и докачки.
- После загрузки база лежит локально, сеть больше не нужна никогда. Кнопки «Загрузить» и «Удалить базу толкований» — в настройках, с указанием размера.
- Толкование доступно тапом по слову в журнале партии и на итоговом экране.

## UX и нефункциональные требования

- Экраны: Главное меню → Новая игра (настройки) → Жребий → Игра → Заслонка передачи хода → Итоги. Плюс Настройки, Правила, О программе.
- Игровое поле масштабируется под ширину экрана; буквы читаемы на 5", поле 7×7 помещается без прокрутки.
- Состояние партии переживает поворот экрана, сворачивание и убийство процесса: при возврате партия продолжается с того же хода (сериализация состояния в DataStore/файл). При запуске, если есть незавершённая партия, предлагать «Продолжить».
- Светлая и тёмная темы, локализация интерфейса — русский.
- Тактильный отклик на постановку буквы и на подтверждение слова, звуки — опционально и отключаемо.
- Экран «Правила» с кратким описанием: как ходить, что считается словом, как считаются очки.
- Доступность: контрастность, размеры тапа не менее 48 dp, `contentDescription` для клеток поля.

## Чего делать не нужно

Онлайн-режим, игра по сети, игра против ИИ-соперника, аккаунты, рейтинги, облачные сохранения, реклама, покупки, аналитика, сбор любых персональных данных, разрешения кроме `INTERNET`.

## Порядок работ

1. Каркас проекта + доменное ядро (модель поля, валидатор хода, подсчёт очков, условия конца игры) + unit-тесты на правила, включая проверку «слово уже читается на поле».
2. Скрипт сборки словаря, упаковка в assets, API проверки слова и поиска подсказки + тесты производительности.
3. UI: меню, настройки, жребий, поле, ввод буквы и выделение пути, журнал слов, итоги.
4. Таймер, пасы, подсказки, сдаться, заслонка передачи хода, сохранение/восстановление партии.
5. Подсистема толкований: загрузка, хранение, карточка слова, поведение без сети.
6. Полировка: темы, доступность, экран правил и лицензий, release-сборка.

После каждого этапа — рабочая сборка и краткий отчёт, что сделано и какие решения приняты.

# Ожидаемый результат

- Git-репозиторий с проектом на Kotlin/Compose, собирающийся командой `./gradlew assembleRelease` без ручных шагов.
- Подписанный отладочный APK, устанавливающийся на Android 8.0+, в котором партию 5×5 можно сыграть от начала до конца в авиарежиме.
- Доменные unit-тесты, покрывающие все правила валидации хода, подсчёт очков и условия завершения партии; тесты проходят в CI или локально одной командой.
- Скрипт и README для пересборки словаря проверки слов и базы толкований, с указанием источников и лицензий.
- README проекта: архитектура, структура модулей, как собрать, как обновить словари.
- Экран «О программе» с указанием лицензий использованных словарных данных.

**Принятые допущения (подтвердить или изменить):**
- Проход по одной клетке дважды запрещён (вариант «колокол» из К, О, Л не поддерживается).
- Игроков всегда двое — режим на 3–4 игроков не делаем.
- Штраф за подсказку — 5 очков; за сдачу — обнуление счёта сдавшегося.
- Язык игры и словарей — только русский.
