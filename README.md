# Балда — офлайн-игра для двоих на Android

Классическая игра в слова на одном телефоне (hot-seat). Полностью офлайн: словарь проверки слов
упакован в APK, толкования слов докачиваются один раз по желанию пользователя. Без аккаунтов,
рекламы, аналитики и сбора данных. Единственное разрешение — `INTERNET`, и только для загрузки
базы толкований.

Постановка задачи — в [docs/balda-android-task.md](docs/balda-android-task.md).

## Сборка

Требования: JDK 17, Android SDK (platform 36, build-tools 36), Python 3.10+ только для пересборки словарей.

```bash
./gradlew :core:test            # доменные unit-тесты, включая тесты производительности словаря
./gradlew assembleDebug         # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease       # app/build/outputs/apk/release/app-release.apk (R8, подпись отладочным ключом)
```

Путь к SDK — в `local.properties` (`sdk.dir=...`), файл не коммитится.

Релизная сборка подписывается отладочным ключом, чтобы `assembleRelease` работал без ручных шагов.
Для публикации положите свой keystore в `keystore/release.jks` и параметры в `keystore/release.properties`
(`storePassword`, `keyAlias`, `keyPassword`) — они подхватятся автоматически.

## Архитектура

Single Activity, Jetpack Compose, MVVM (`ViewModel` + `StateFlow`), корутины.

```
core/    чистый Kotlin/JVM-модуль без Android-зависимостей: правила игры и словарь
app/     Android-приложение: данные, ViewModel, Compose-экраны
tools/build-dictionary/   скрипты сборки словарей (Python)
```

### `core` — доменное ядро

| Файл | Назначение |
|---|---|
| `Board.kt` | Неизменяемое поле N×N, клетки, соседство (только ортогональное) |
| `Model.kt` | `GameSettings`, `GameState`, `PlayerState`, журнал `LogEntry`, статус партии — всё `@Serializable` |
| `MoveValidator.kt` | Все проверки хода; возвращает типизированную причину `MoveError` |
| `BoardWords.kt` | Обход в глубину: читается ли слово на поле (правило «слово уже читается») |
| `GameEngine.kt` | Переходы состояния: ход, пас, таймер, подсказка, сдача, условия конца партии, победитель |
| `HintFinder.kt` | Поиск подсказки перебором пустых клеток и букв с отсечением по префиксам словаря |
| `StartWordPicker.kt` | Случайное стартовое слово нужной длины без повторов в сессии |
| `dictionary/` | `WordDictionary` (отсортированный массив + бинарный поиск) и бинарный формат `words.bin` |

Тесты в `core/src/test` покрывают все правила валидации, подсчёт очков, условия завершения,
сериализацию состояния и производительность на реальном словаре (загрузка < 1 с, проверка < 10 мс,
подсказка < 2 с).

### `app`

- `data/` — `SettingsRepository` (DataStore: имена, параметры партии, тема, звук, вибрация),
  `GameRepository` (текущая партия в JSON-файле, переживает поворот и убийство процесса),
  `DefinitionsRepository` (загрузка SQLite-базы толкований с докачкой по `Range`, проверка SHA-256, чтение),
  `AppContainer` (зависимости без DI-фреймворка).
- `ui/game/` — `GameViewModel` (ввод хода, таймер, подсказки, заслонка, автосохранение), `BoardView`
  (поле с тапом и ведением пальцем), `LetterKeyboard`.
- `ui/screens/` — Меню, Новая игра (+ жребий), Игра (+ заслонка «Передай телефон», журнал), Итоги,
  Настройки, Правила, О программе, карточка толкования.

Состояние партии сохраняется после каждого изменения в `filesDir/current_game.json`; при запуске
меню предлагает «Продолжить». Если таймер хода истёк, пока приложение было закрыто, при возврате
ход засчитывается как пас.

## Словари

Подробно — в [tools/build-dictionary/README.md](tools/build-dictionary/README.md).

- **Проверка слов** (`app/src/main/assets/words.bin`, ~500 КБ, ~51 000 слов): список нарицательных
  существительных [Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns) (MIT, получен из
  OpenCorpora, CC BY-SA 4.0). Ё нормализована в Е. Пересборка: `python tools/build-dictionary/build_words.py --download`.
- **Стартовые слова** (`start_words.txt`): существительные 5–7 букв из 30 000 самых частых словоформ
  ([FrequencyWords](https://github.com/hermitdave/FrequencyWords), CC BY-SA 4.0).
- **Толкования** (`definitions.db`, ~9 МБ, ~44 000 слов): дамп Русского Викисловаря (CC BY-SA 4.0).
  Пересборка: `python tools/build-dictionary/build_definitions.py --download`. Файлы `definitions.db` и
  `definitions.db.sha256` публикуются как assets релиза GitHub; адрес задаётся в `gradle.properties`
  (`balda.definitionsUrl`, `balda.definitionsSha256Url`). Если адрес пуст, кнопка загрузки неактивна,
  игра работает без толкований.

## Принятые решения

- Проход по одной клетке дважды запрещён; диагонали запрещены; игроков всегда двое.
- Штраф за подсказку настраивается (0/3/5/10, по умолчанию 5); лимит 0/1/3/∞ (по умолчанию 1).
  Подсказка показывает только слово, без пути.
- Сдача — обнуление счёта сдавшегося, победа сопернику. Шесть пасов подряд — конец партии, победитель по очкам.
- «Играть ещё раз с теми же настройками» берёт новое стартовое слово той же длины, первым ходит другой игрок.
- Аббревиатуры (вуз, загс и т. п.) исключены стоп-листом; слова с дефисом и имена собственные — фильтром.
